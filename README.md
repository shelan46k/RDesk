# RDesk

Windows 11 桌面管理助手。側邊欄加上可釘在桌面上的文件格子，常用檔案、待辦和隨記都放在手邊；不用的時候整個收起來，桌面不會留下懸浮球。

## 下載

**[下載最新安裝檔（RDesk-win-Setup.exe）](https://github.com/shelan46k/RDesk/releases/latest)**

- 系統：Windows 11，64 位元
- 第一次開啟若出現「Windows 已保護你的電腦」，選 **其他資訊 → 仍要執行**（目前沒有程式碼簽章）
- 用這個安裝包裝過之後，之後有新版本會自動檢查並更新

## 能做什麼

- **側邊欄**：天氣與時鐘、最近開啟的檔案、常用收藏、待辦 / 隨記、正在播放的音樂、系統與網路狀態
- **藏起來很乾淨**：按隱藏後桌面不留任何物件，只留右下角系統匣圖示；再點圖示，或按 **F7**，就能叫回來
- **桌面文件格子**：把收藏或資料夾釘到桌面上自由擺放，檔案可以直接拖進去整理
- **一鍵整理桌面**：依副檔名規則把桌面檔案歸類（可預覽再執行，也能還原）
- **快速搜尋**：預設 **Ctrl + Alt + F** 搜尋本機檔案
- **外觀**：淺色 / 深色、亞克力或雲母材質，背板和格子透明度可分開調整
- **資料在本機**：設定、待辦、隨記都存在自己電腦，可備份成 ZIP 再還原

## 常用操作

| 動作 | 預設方式 |
| --- | --- |
| 顯示 / 隱藏側邊欄 | F7，或點右下角系統匣圖示 |
| 搜尋 | Ctrl + Alt + F |
| 把桌面格子提到最前面 | Ctrl + Alt + B |
| 偏好設定 | 側邊欄右上角「設置」 |

快捷鍵都可以在偏好設定裡改。

## 給想自己編譯的人

需要 .NET 8 SDK。Debug：

```powershell
dotnet build src\RDesk\RDesk.csproj -c Debug -p:Platform=x64
```

打包安裝檔：

```powershell
powershell -ExecutionPolicy Bypass -File .\publish-release.ps1 -Version 1.0.1
```

打上 `v1.0.1` 這種 tag 並 push 之後，GitHub Actions 會自動編譯並上傳到 Releases。
